## Рекомендации для дальнейшей работы

1. Учитывать CRM-признаки при очистке данных.
2. Выполнять разбиение train/val/test
   с группировкой по text.
3. Исключить пересечение одинаковых текстов
   между выборками.
4. Согласовать стратегию работы с редкими классами.
5. Оценивать качество на уникальных текстах
   и на естественном тестовом потоке с повторами.
6. Использовать естественный тестовый поток
   для оценки containment и Semantic Cache.
7. Не использовать resolution_type как входной
   признак при прогнозировании этой целевой метки.
